# 팬직 현장 시뮬레이터

환경 조건에 맞는 팬직(FANZIC) 제품을 실물 사진으로 추천하고, 흡기·배기 효과와 설치 과정을 3D로 보여주는 웹 앱입니다. 고객 상담과 영업 담당자 학습·타깃 발굴에 함께 씁니다.

**바로 열기:** https://smkwon77-sketch.github.io/fanzic-site-simulator/

## 세 가지 보기

### 1. 환경에서 찾기 (고객 상담)
① 환경 설정 → ② 제품 선택 → ③ 설치 과정 → ④ 효과 → ⑤ 상담 요약
- **환경 설정**: 공간 용도(주거·상업/사무·병원·주방·공장·창고·축사·서버실·플랜트·고습·온실·지하주차장), 면적, 천장 높이, 주된 문제(열기·습기·냄새/유증기·미세먼지·CO₂·유해가스·공기 정체), 설치 가능 위치(벽·천장·지붕·바닥·덕트), 특이사항(부식·기름기·저소음)
- **추천**: 조건에 맞는 제품을 역할별(주 환기·순환·필터·부속)로 2~4종 골라 **실물 사진 카드**와 추천 이유로 보여 주고, "다른 제품 보기"에서 다시 고를 수 있습니다.
- **흡기/배기**: 제품마다 흡기·배기를 바꿀 수 있고, 3D에서 흡기는 **파란 신선 공기가 실내로**, 배기는 **주황 공기가 밖으로** 나가는 모습과 화살표로 다르게 보입니다.

### 2. 제품에서 찾기 (영업 학습·타깃 발굴)
- 제품 사진 목록 → 제품 상세: 3D 단독 보기(흡기/배기 기류), 사양·특징, 같은 제품군 비교(풍량·전력)
- **이런 환경에 맞아요**: 용도 12종을 추천 점수 순으로 정렬, 바로 시뮬레이션
- **이런 고객을 찾아보세요**: 상위 용도의 고객군·발굴 단서·상담 첫 질문·영업 포인트(초안)

### 3. 적합도 표
제품 × 용도 ◎○△ 표. 칸을 누르면 그 조합으로 시뮬레이션합니다.

## 내 PC에서 실행

```bash
python -m http.server 8790
```

브라우저에서 `http://localhost:8790` 을 엽니다. 3D 라이브러리(three.js r128)를 CDN에서 받으므로 인터넷 연결이 필요합니다.

## 고쳐 쓰는 파일

| 파일 | 내용 |
|---|---|
| `data/products.js` | 제품 사양(풍량·전력·정압·특징), 메트릭스 외 적합도, 공통 가정값 |
| `data/tags.js` | 추천용 태그(해결 문제·흡기/배기·적합 면적·소음·내부식), **제품 사진 파일 이름** |
| `data/matrix.js` | 「제품별 용도 메트릭스.xlsx」 적합도(◎○△) |
| `data/sites.js` | 용도별 기본 조건, 환경 → 가상 공간 변환, 추천 점수 규칙 |
| `data/sales.js` | 용도별 고객군·발굴 단서·첫 질문·영업 포인트 (**초안**, 영업팀 검토 필요) |
| `assets/products/` | 제품 실물 사진 |

사진이 없는 제품(온실 전용팬·서리방지팬·서큘레이션팬·대형 덕트 인라인팬·EC 팬 모듈)은 3D 모델 그림으로 대신 보여 줍니다. 사진을 `assets/products/`에 넣고 `data/tags.js`의 `image`에 파일 이름을 적으면 바뀝니다.

## 수치에 대해

- 적합도는 「제품별 용도 메트릭스」 기준이며, 메트릭스에 없는 용도·제품은 브로셔 용도 문구를 기준으로 "메트릭스 외"로 표시합니다.
- 추천 점수 = 용도 적합도 + 해결하는 문제 + 대수 적정성 + 용도 대표 제품 + 특이사항. 설치할 수 없는 위치의 제품은 빠집니다.
- 제품 사양은 카탈로그 대표 모델(50Hz, 일부 60Hz) 기준이며, 일부 수치(팬도라·퓨리젠 풍량, HVLS 커버 면적 등)는 가정값입니다.
- 효과는 단순 모델로 계산한 **참고 추정치**이며 성능을 보증하지 않습니다. 정확한 선정은 현장 실측 후 팬직 기술지원팀과 진행합니다.
