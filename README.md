# 팬직 현장 시뮬레이터

팬직(FANZIC) 제품을 현장에 맞게 골라 설치하는 과정과, 설치 후 효과를 3D로 보여주는 영업 상담용 웹 앱입니다.

**바로 열기:** https://smkwon77-sketch.github.io/fanzic-site-simulator/

## 할 수 있는 것

- **현장 12곳**: 회사 「제품별 용도 메트릭스」의 10곳(주택·상업시설·병원·식당·공장·물류센터·축사·데이터센터·플랜트·수영장)과 온실·지하주차장
- **현장별 추천 제품 선택**: 그 현장에 맞는 제품을 ◎최적 · ○적합 · △가능 순으로 보여주고, 카드를 눌러 넣고 뺄 수 있습니다. 제품군(시로코팬·환풍기·덕트팬·고압팬·송풍기·대형 실링팬·필터·부속·EC팬)으로 걸러 볼 수 있습니다.
- **권장 대수 자동 산정**: 현장 목표 환기량을 선택한 배기 제품들이 나눠 맡도록 대수를 계산하고, ± 버튼으로 조정할 수 있습니다. 실링팬은 커버 면적, 필터·디퓨져는 면적 기준으로 잡습니다.
- **설치 과정 6단계**: 위치 선정 → 개구부·앵커·덕트 → 브라켓 → 본체 거치 → 배선 → 시운전을 3D 애니메이션으로 보여주고, 벽 관통형·덕트형·천장형·외벽 마감형 등 설치 방식별 설명이 붙습니다.
- **효과 시뮬레이션(가동 후 60분)**: 공기 흐름 입자, 바닥 온도·공기질 색상, 환기 횟수·오염물·미세먼지·체감온도·풍속·전력 KPI, 시간에 따른 변화 차트
- **상담 요약**: 선택 제품(적합도 포함)과 기존 대비 효과를 한 장으로 정리하고 텍스트로 복사

## 내 PC에서 실행

```bash
python -m http.server 8790
```

브라우저에서 `http://localhost:8790` 을 엽니다. 3D 라이브러리(three.js r128)를 CDN에서 받으므로 인터넷 연결이 필요합니다.

## 파일 구조

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 레이아웃·스타일 |
| `data/products.js` | 제품 사양(풍량·전력·정압·특징)과 공통 가정값(전기요금, 배출계수, EC 절감률 등), 메트릭스 외 현장·제품 적합도 |
| `data/matrix.js` | 「제품별 용도 메트릭스.xlsx」에서 옮긴 현장별 적합도(◎○△) |
| `data/sites.js` | 현장별 크기·조건·목표 환기량·기본 추천 제품, 제품 선택·배치 규칙 |
| `js/sim.js` | 효과 계산 모델 |
| `js/models.js` | 팬·건물·내부 소품 3D 모델, 제품 배치 |
| `js/scene.js` | 렌더러, 카메라 조작, 디오라마 지도 |
| `js/effects.js` | 공기 흐름 입자, 바닥 히트맵, 차트 |
| `js/install.js` | 설치 6단계 설명과 애니메이션 |
| `js/app.js` | 화면 상태와 패널 구성 |

메트릭스 엑셀이 바뀌면 `data/matrix.js`의 ◎○△ 값을 같이 고치면 됩니다.

## 수치에 대해

- 적합도는 「제품별 용도 메트릭스」 기준입니다. 메트릭스에 없는 현장(온실·지하주차장)과 제품(온실 전용팬, 루프팬, 서리방지팬, 서큘레이션팬, 대형 덕트 인라인팬, 유인 제트팬, EC 팬 모듈, 대형 베인 축류팬)은 브로셔 용도 문구를 기준으로 추천했고 화면에 "메트릭스 외"로 표시합니다.
- 제품 사양은 2026 브로셔·2025 국문 카탈로그 대표 모델(50Hz) 기준이며, 일부 제품은 "60Hz 사양"으로 표시합니다. 팬도라·퓨리젠 풍량, HVLS 커버 면적, 유인 제트팬·EC 팬 모듈 수치는 카탈로그에 없어 **가정값**으로 넣었습니다.
- 효과는 단순 모델로 계산한 **참고 추정치**이며 성능을 보증하지 않습니다.
  - 환기·필터: `C∞ = (Q·C외기 + 발생량) / (Q + 필터 CADR)`, `C(t) = C∞ + (C₀ − C∞)·e^(−(Q+CADR)/V·t)`
  - 온도: `T = T외기 + 발열 / (UA + Q/3000)`
  - 체감온도: 풍속에 따른 냉각 효과(사람 최대 4.5℃, 가축 최대 7℃)
- 생산성 환산 계수(체감 25℃ 초과 1℃당 1%, 최대 15%)와 전기요금 등은 앱의 "계산 가정값 바꾸기"에서 바꿀 수 있습니다.
- 정확한 제품 선정은 현장 실측 후 팬직 기술지원팀과 진행합니다.
