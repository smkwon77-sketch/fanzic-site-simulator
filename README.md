# 팬직 현장 시뮬레이터

팬직(FANZIC) 제품을 실제 현장에 설치하는 과정과, 설치 후 효과를 3D로 보여주는 영업 상담용 웹 앱입니다.

**바로 열기:** https://smkwon77-sketch.github.io/fanzic-site-simulator/

## 할 수 있는 것

- **현장 10곳**: 공장, 물류센터, 양계장, 온실, 지하주차장, 식당 주방, 데이터센터, 사무실·학교, 중공업, 수영장
- **권장 구성 자동 산정**: 현장 크기·발열·인원을 넣으면 제품별 권장 대수를 계산하고, ± 버튼으로 조정할 수 있습니다.
- **설치 과정 6단계**: 위치 선정 → 개구부·앵커·덕트 → 브라켓 → 본체 거치 → 배선 → 시운전을 3D 애니메이션으로 보여줍니다. 벽 관통형·지붕형·천장형 등 설치 방식별 설명이 붙습니다.
- **효과 시뮬레이션(가동 후 60분)**: 공기 흐름 입자, 바닥 온도·공기질 색상, 환기 횟수·오염물·체감온도·풍속·전력 KPI, 시간에 따른 변화 차트
- **상담 요약**: 제품 구성과 기존 대비 효과를 한 장으로 정리하고 텍스트로 복사

## 내 PC에서 실행

```bash
python -m http.server 8790
```

브라우저에서 `http://localhost:8790` 을 엽니다. 3D 라이브러리(three.js r128)를 CDN에서 받으므로 인터넷 연결이 필요합니다.

## 파일 구조

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 레이아웃·스타일 |
| `data/products.js` | 제품 사양(풍량·전력·정압 등)과 공통 가정값(전기요금, 배출계수, EC 절감률 등) |
| `data/sites.js` | 현장별 크기·조건·추천 제품·권장 대수 산정 기준 |
| `js/sim.js` | 효과 계산 모델 |
| `js/models.js` | 팬·건물·내부 소품 3D 모델, 제품 배치 |
| `js/scene.js` | 렌더러, 카메라 조작, 디오라마 지도 |
| `js/effects.js` | 공기 흐름 입자, 바닥 히트맵, 차트 |
| `js/install.js` | 설치 6단계 설명과 애니메이션 |
| `js/app.js` | 화면 상태와 패널 구성 |

## 수치에 대해

- 제품 사양은 2026 팬직 브로셔의 최대 성능(60Hz) 기준입니다. 대형 실링팬(HVLS), EC 팬 모듈, 유인 제트팬은 카탈로그 수치를 확인하지 못해 **대표값**을 넣었고, 화면에 "대표값"으로 표시됩니다.
- 효과는 단순 모델로 계산한 **참고 추정치**이며 성능을 보증하지 않습니다.
  - 환기: `C(t) = C∞ + (C₀ − C∞)·e^(−ACH·t)`
  - 온도: `T = T외기 + 발열 / (UA + Q/3000)`
  - 체감온도: 풍속에 따른 냉각 효과(사람 최대 4.5℃, 가축 최대 7℃)
- 생산성 환산 계수(체감 25℃ 초과 1℃당 1%, 최대 15%)와 전기요금 등은 앱의 "계산 가정값 바꾸기"에서 바꿀 수 있습니다.
- 정확한 제품 선정은 현장 실측 후 팬직 기술지원팀과 진행합니다.
